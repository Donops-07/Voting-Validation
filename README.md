# E-Government Voting Validation UI
This project is a strictly front-end web application that validates user input for voting eligibility before form submission. 

### Key Features
* **Empty State Prevention:** The JavaScript logic checks if the first name input is blank or not using the .trim and provide relevant message.
* **Age Verification:** The system evaluates the user's age and triggers an error popup if the age is 18 or older, showing a confirmation and an error message if less than 18.
* **Mutually Exclusive Selection:** The HTML is structured using the radio input to ensure a user can only select one gender.

### Technologies Used
* HTML5
* Vanilla CSS (Custom positioning and flexbox)
* Vanilla JavaScript (DOM manipulation and client-side validation)
